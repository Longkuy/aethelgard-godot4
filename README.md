## 🚀 วิธีเปิดรันและ Export ใน Godot 4

1. เปิด **Godot Engine 4.3+** -> กด **Import** เลือกไฟล์ `project.godot` -> กด **Run Project (`F5`)** เข้าเล่นได้ทันที!
2. หากต้องการสร้างไฟล์เกมแยกเดี่ยว (`.exe` / Linux / Web): ไปที่เมนู **Project -> Export...** จะพบโปรไฟล์ Windows Desktop, Linux/X11 และ Web (HTML5) ที่ตั้งค่าเตรียมไว้ให้แล้วใน `export_presets.cfg`

### ปุ่มควบคุมหลัก
- `WASD` / `Arrow Keys` หรือ **คลิกซ้ายบนพื้น**: เดิน (`Shift` วิ่งเร็ว)
- `E` / `Space` / `Enter`: โต้ตอบ พูดคุย อุ้มลูก เก็บของป่า ตกปลา หมุนเสาแสง เดินบทคัตซีน
- `F`: ปล่อยคลื่นแสงศักดิ์สิทธิ์ชำระล้างภูตหมอกเงามืด & บอสชั้น B4
- `9`: เปิด/ปิดตะเกียงส่องทางยามค่ำคืน • `P`: ลูบหัวสัตว์เลี้ยงคู่หู
- `H`: โหมดวางเฟอร์นิเจอร์บนตารางในบ้าน (`R` หมุนทิศทาง) • `M`: แผนที่วาร์ป • `Tab`: ข้ามฉากคัตซีน
